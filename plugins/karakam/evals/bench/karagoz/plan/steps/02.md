# Step 02: KDV hesabı ve TL biçimi

## Goal
`stokcu/fiyat.py` içinde saf fiyat fonksiyonları: `kdvli` ve `tl_bicimle`.

## Dependencies
depends_on: []

## Effort
effort: medium
critical: false
rationale: iki saf fonksiyon; kurallar tam belirli.

## Relevant methodology
Para `Decimal`, `float` yasak. `kdvli(tutar, oran=Decimal("0.20")) -> Decimal`
iki haneye ROUND_HALF_UP yuvarlar. `tl_bicimle(tutar) -> str` Türk biçimi:
binlik ayırıcı nokta, ondalık virgül, iki hane, sonda " TL". Testler pytest.

## Worker prompt
`stokcu/fiyat.py` oluştur (paket `__init__.py`'si 01. adımın işi; bu adım onu
oluşturmaz — testlerde modülü `stokcu.fiyat` olarak import et, pytest'i depo
kökünden çalıştır):
- `kdvli(tutar: Decimal, oran: Decimal = Decimal("0.20")) -> Decimal`:
  `tutar * (1 + oran)`, `Decimal("0.01")`'e `ROUND_HALF_UP` ile yuvarlanmış.
  `tutar` ya da `oran` negatifse `ValueError`.
- `tl_bicimle(tutar: Decimal) -> str`: önce iki haneye ROUND_HALF_UP yuvarla,
  sonra Türk biçimi: `Decimal("1234.5")` → `"1.234,50 TL"`,
  `Decimal("0")` → `"0,00 TL"`, `Decimal("1000000")` → `"1.000.000,00 TL"`,
  `Decimal("-12.345")` → `"-12,35 TL"`. `locale` modülünü kullanma.
`tests/test_fiyat.py` içinde bu örneklerin hepsini ve yuvarlama sınırlarını
(`kdvli(Decimal("10.00"))` → `Decimal("12.00")`, `kdvli(Decimal("0.125"), Decimal("0"))`
→ `Decimal("0.13")`) test et.
